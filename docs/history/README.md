# Early phases

Reports from the project's first phase (camera and imagery validation),
kept as they were written. They describe the code and the data of that
time; some of it has since changed or gone, and each says so at the top
where it matters:

- `PHASE_1.md`: validating the delivered camera models against the imagery.
- `walkthrough.md`: the walkthrough of that phase. Its section 7 describes
  Jupyter notebooks, which were removed in September 2026.
- `URBAN_AOI.md`: choosing the first tower, and the first run on it.
- `ROOF_GEOMETRY.md`: finding a single building's roof, including a domed
  crown.
- `WHAT_THE_QA_MEASURES.md`: what the camera checks measured, and where they
  were fooled.

For the pipeline as it is now, start at the [README](../../README.md) and
[CLOUD.md](../CLOUD.md).
